# 走过页面行政区边界数据

完整目录保存在 `data/jingzhe/zouguo_boundary_catalog.json`，只在 Hugo 构建期使用。页面资源由 Hugo 按生成数据中的国家、省/州和城市代码自动裁剪；浏览器不会下载完整目录。

## 世界国家边界

国家级边界来自 [Natural Earth](https://www.naturalearthdata.com/) 的 1:110m Admin 0 Countries，版本 5.1.2。Natural Earth 数据属于 Public Domain。
