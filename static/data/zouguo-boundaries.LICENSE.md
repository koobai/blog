## 阿联酋与科威特边界

海外边界来自 [geoBoundaries 6.0.0 gbOpen](https://www.geoboundaries.org/)，固定于仓库提交 `9469f09`，仅保留阿联酋、科威特、迪拜酋长国、科威特首都省及 Sharq 区等本原型使用的几何数据。

- 阿联酋 ADM0：Public Domain。
- 阿联酋 ADM1、科威特 ADM0/ADM1/ADM2：来源于 OpenStreetMap、Wambacher，经 geoBoundaries 标准化，使用 [Open Data Commons Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/)。
- 数据归属：[geoBoundaries](https://www.geoboundaries.org/) 与 [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)。
